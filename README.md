## emptech-en — EMPTECH homepage demo

This branch `emptech-demo` contains a simple high-fidelity demo for an EMPTECH corporate homepage using plain HTML/CSS/JS.

Files added:
- index.html
- css/styles.css
- js/main.js

Preview:
- Clone the repo and checkout branch emptech-demo
- In project root run:
  - python3 -m http.server 8000
  - Open http://localhost:8000 in your browser
Or open index.html directly.
